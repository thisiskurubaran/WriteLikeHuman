# Buzzwords and plain replacements

Use this list with `writing/resume.md`, and for any business or work writing. The replacement is a starting point. Pick what fits the sentence and the facts. Sometimes the best fix is to delete the word.

This file lists stock words on purpose so they can be found and replaced.

## Resume buzzwords

| Buzzword | Plain replacement |
|---|---|
| Spearheaded | Led, started, ran |
| Orchestrated | Organised, ran, planned |
| Leveraged | Used |
| Utilised | Used |
| Facilitated | Ran, helped, led |
| Championed | Pushed for, backed, led |
| Synergised | Worked with |
| Drove (growth, results) | Increased, grew (only with the real number if the user gave one) |
| Results-driven | Delete. Show the result instead |
| Detail-oriented | Delete, or name what they checked carefully |
| Self-starter | Delete, or say what they started on their own |
| Team player | Delete, or say who they worked with |
| Go-getter | Delete |
| Proven track record | Delete. List the actual record |
| Passionate about | Interested in, enjoy, or delete |
| Dynamic | Delete |
| Seasoned professional | Name the years: "eight years in accounts" |
| Thought leader | Delete |
| Responsible for | Name the action: handled, managed, ran |
| Played a key role in | Helped, worked on, led (whichever is true) |
| Instrumental in | Helped |
| Exceeded expectations | Say what was done, with the user's numbers |
| Best-in-class | Delete |
| Hands-on experience | Experience |
| Strong communication skills | Name the communication: "wrote the weekly client report" |
| Excellent interpersonal skills | Delete, or give an example from the resume |
| Out-of-the-box thinker | Delete |

## Indian office phrases

These are common in Indian business writing. They are not wrong, but some hide the meaning. Replace only when a plainer phrase is clearer, and keep the user's register.

| Phrase | Plainer |
|---|---|
| Do the needful | Say what needs doing |
| Revert back | Reply |
| Kindly revert at the earliest | Please reply by <date>, or please reply soon |
| PFA (please find attached) | I've attached |
| As per our telecon | As we discussed on the call |
| Prepone | Move earlier (prepone is fine in Indian English, keep it for Indian readers) |
| Intimate (as in "intimate the office") | Inform, tell |

## How to use this list

- Replace a buzzword only when the plain version keeps the meaning.
- If a bullet is only buzzwords with no facts underneath, flag it rather than inventing facts to fill it.
- Do not swap every instance mechanically. Read the sentence after.
