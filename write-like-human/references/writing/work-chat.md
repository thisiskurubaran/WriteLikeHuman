# Work chat messages

Messages for Slack, Microsoft Teams, Google Chat, and similar work chat: status updates, asking for help, replying in a thread, pushing back politely, and announcements to a channel.

## When this applies

- "Write a Slack message to my team", "reply to this Teams thread", "how do I ask my lead for help without sounding lost?"
- A standup or status update, a handover note, a "heads up" about a delay, a channel announcement.
- Saying no, or pushing back on a deadline or a request, in chat.
- The user pastes a draft that reads like an email or a press release, or a message that's too blunt.

## What stays the same

- Names, @mentions, channel names, ticket ids, links, dates, times, and numbers.
- What the user is asking for or reporting. Never add a commitment ("I'll have it done by Friday") they didn't make.
- The team's tone. A casual channel stays casual, a client channel stays polite.

## Steps

1. Put the point first. Chat is read in a glance: the ask, the update, or the answer goes in the first line. "Can you review PR 482 today? It blocks the release."
2. Keep it short. Usually one to four lines. Use a short bulleted list only for three or more separate items.
3. Make asks easy to answer: one clear question, with what you've already tried if asking for help. "The build fails on step 3 with a timeout. I've retried twice. Any idea what changed?"
4. Status updates: done, next, blocked. Skip what nobody needs.
5. Pushing back: say the constraint and offer an option. "I can't take this on before Thursday because of the audit. I could start Friday, or Priya might have time sooner."
6. Drop email habits: no "Hope you're doing well", "Dear team", "Kind regards", or "Please find below". A short greeting like "Hi Arun," is fine.
7. Emoji and reactions: match what the user already uses. Don't add them.

## Output

The message, ready to paste, then a short change summary. For a thread reply, just the reply.

## Example

Before:

> Dear Team, I hope this message finds you well. I wanted to reach out to inform you all that unfortunately the deployment that was scheduled for today will need to be postponed due to some unforeseen issues that have arisen with the payment service. Kind regards, Neha

After:

> Heads up: today's deployment is moved because of a problem with the payment service. I'll post the new time here once it's fixed.

What I changed
- Put the news first and cut the email greeting and sign-off.
- Kept the reason. I added "I'll post the new time here", so remove it if you didn't plan to.
