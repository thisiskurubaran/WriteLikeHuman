# Alt text and image descriptions

Help people write short descriptions of images for those who can't see them: alt text on websites, image descriptions on Instagram and Facebook, and descriptions of pictures in slides and documents.

For a wider readability check of a document or page, see `adjust/accessibility.md`.

## When this applies

- "Write alt text for this photo."
- A small business adds product photos to a website or Instagram.
- A slide deck or Word file has images with no descriptions.
- The user pastes alt text that is a filename ("IMG_2041.jpg"), a stuffed keyword list, or a long paragraph.

## What stays the same

- Product names, prices, and any text visible in the image that the user wants included, copied exactly.
- The purpose of the image as the user explains it. A product photo and a team photo need different descriptions.

## What not to do

- Never guess who a person is, or their ethnicity, religion, caste, age, health, or disability. Describe what is visible: "a woman in a blue saree holding a cake".
- Don't start with "Image of" or "Picture of". Screen readers already announce it as an image.
- Don't add feelings or claims the picture doesn't show ("happy customers loving our product").
- Don't stuff keywords for search.

## Steps

1. Ask what the image is for, if it's not clear. The context decides what matters.
2. Describe the important part first. For a product: what it is, colour, material if visible. For a chart: the main point, not every number. For a photo of a place or event: who or what, doing what, where.
3. Keep most alt text to about 125 characters. Longer descriptions are fine for Instagram captions or complex charts, but put the key point in the first sentence.
4. If the image contains important text (a poster, a sign, a price tag), include that text, exactly as written.
5. If the image is only decoration (a divider, a background pattern), say it can have empty alt text so screen readers skip it.
6. For several images, keep descriptions consistent in style but specific to each image.

## Output

The alt text or description for each image, labelled if there are several, ready to paste. For decorative images, say so in one line.

## Example

Before (website product photo):

> IMG_2041.jpg handmade candle soy candle best candle gift India

After:

> Lavender soy candle in a frosted glass jar with a wooden lid.

What I changed
- Replaced the filename and keyword list with what the photo actually shows.
- Kept it under 125 characters so screen readers read it in one go.
