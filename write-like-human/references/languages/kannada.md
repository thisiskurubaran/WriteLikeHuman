# Kannada

Rewrite Kannada so it sounds like a person wrote it, in the register the situation needs.

## When this applies

- The text is in Kannada, in Kannada script or in Roman script.
- The user asks for a translation into Kannada (also load `translate-humanize.md`).
- For Kannada mixed with English (Kanglish), load `mixed-language.md` as well.

## What stays the same

- Language and script. Kannada stays Kannada. Never translate unless asked.
- Names, numbers, dates, amounts, and places.
- The register. "ನೀವು" (respectful) stays "ನೀವು". "ನೀನು" (informal) stays "ನೀನು".
- Everyday English words people use in Kannada (bus, phone, office), unless the user avoids them.

## AI tells in Kannada

- Formal written Kannada in casual text. Literary verb forms in a message to a friend, where spoken forms like "ಬರ್ತೀನಿ" are normal.
- Forced pure Kannada words for things people name in English.
- Literal English calques, like word for word "I hope you are doing well".
- Too formal or too casual for the reader.
- Repeated sentence shape and endings.

Official letters and school writing stay in standard written Kannada. Fix stiffness, keep the register.

## Steps

1. Work out the reader and keep the user's register.
2. Use spoken forms in casual text, written forms in formal text.
3. Rewrite calques the way a Kannada speaker would say them.
4. Vary sentence length.
5. Check names, numbers, and dates are unchanged.

## Output

The rewritten Kannada text, then a short **What I changed** list in the language the user is using with you. Describe the changes in plain words, without word-by-word English glosses of the rewritten text.

## Example

Before (to a friend): "ಸ್ನೇಹಿತನೇ, ನಾನು ನಾಳೆ ಬರುತ್ತೇನೆ ಎಂದು ತಿಳಿಸುತ್ತೇನೆ."

After: "ನಾಳೆ ಬರ್ತೀನಿ ಕಣೋ."

Gloss: The first reads like a notice: "Friend, I inform you that I will come tomorrow." The second is how you would text a friend: "I'll come tomorrow, man."
