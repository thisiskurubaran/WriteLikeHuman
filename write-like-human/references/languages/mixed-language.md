# Mixed language writing

Hinglish, Tanglish, Benglish, Kanglish, Manglish, and other writing that mixes English with an Indian language. Most people in India text this way. Treat it as normal writing, not as a mistake.

## When this applies

- The text mixes English with Hindi, Tamil, Bengali, Malayalam, Kannada, or another language in the same message or sentence.
- The user asks for a reply "in Hinglish" or "the way I normally text".

## What stays the same

- The mix. If the user writes about half English and half Hindi, keep it about half and half. Do not turn it into pure English or pure Hindi.
- The script. Roman script stays Roman ("kal milte hain"). Devanagari stays Devanagari. Mixed scripts stay mixed. Do not switch scripts unless asked.
- Their spelling of Romanized words. If they write "acha", do not change it to "accha" or "achha". There is no single right spelling.
- Names, numbers, dates, amounts, and places.
- The tone. Casual stays casual.

## AI tells in mixed writing

- Over-formal Hindi in casual chat. "Kripya", "dhanyavaad", "avashya", "aapka swagat hai" in a message to a friend. People say "please", "thanks", "pakka", "sure".
- Forced English. Turning "kal aa jaana" into "please come tomorrow" when the chat was in Hinglish.
- Textbook grammar on both sides. Full, perfect English sentences with one Hindi word stuck on the end to look casual.
- Fake slang. Adding "yaar", "bro", "macha", or "da" to every line. Use them only where the user already does, and only as often.
- Consistent spelling. Real Romanized text varies. A rewrite that spells every word the same "correct" way can feel stiff. Keep the user's spellings.
- Too many emojis or none at all. Match what the user does.

Tanglish notes: keep "da", "di", "machan", "seri", "paravala" only where the user uses them. Do not swap everyday Tanglish for pure literary Tamil.

Benglish notes (Bengali and English): keep "na", "toh", "achha", "ki holo", "bhalo", "chol" as the user writes them. Do not turn a casual Benglish message into formal "sadhu bhasha" Bengali.

Manglish notes (Malayalam and English): keep "alle", "aano", "entha", "machane", "scene illa" only where the user uses them. Do not swap them for formal Malayalam like "dayavayi" or "ariyikkuka" in a chat.

Kanglish notes (Kannada and English): keep "guru", "maga", "swalpa", "beda", "adjust maadi" as the user writes them. Do not replace everyday words with textbook Kannada.

## Steps

1. Work out the base language (the grammar) and the mix ratio.
2. Note the script and the user's spellings.
3. Fix only what reads as stiff or robotic. Keep the rhythm of a text message: short lines, few full stops.
4. Check you did not add slang, formal words, or English the user did not use.

## Output

The rewritten message, then a short **What I changed** list. If you were asked to reply to a message, give the reply only, in the same mix.

## Example

Before (sounds like a bot): "Kripya mujhe bataiye ki aap kal meeting ke liye available hain ya nahi. Aapke uttar ki pratiksha rahegi."

After: "Kal meeting ke liye free ho? Bata dena."

Gloss: The first version uses formal textbook words ("kripya", "uttar ki pratiksha") that nobody uses with a colleague on WhatsApp. The rewrite says the same thing the way people actually text: "Free for the meeting tomorrow? Let me know."

Tanglish example.

Before: "Nanba, naalai naan varuvadhu urudhi illai. Mannikkavum."

After: "Machan, naalaiku vara mudiyumanu theriyala da. Sorry."

Gloss: "Friend, not sure I can come tomorrow. Sorry." The first version is written like a letter. The second is how the user would text a friend.

Benglish example.

Before: "Priyo bondhu, anugroho kore amake janaben apni kal ashben kina."

After: "Kal ashchis toh? Janash."

Gloss: "You're coming tomorrow, right? Let me know." The first is formal Bengali with "apni" that nobody uses with a close friend in a chat.

Manglish example.

Before: "Dayavayi naale meetingil pankedukkumo ennu ariyikkuka."

After: "Naale meeting undu, varille? Para."

Gloss: "There's a meeting tomorrow, you're coming, right? Tell me." The first sounds like an office circular.

Kanglish example.

Before: "Dayavittu naale karyakramakke barutteero illavo tilisi."

After: "Maga, naale function ge bartiya? Helu."

Gloss: "Dude, are you coming to the function tomorrow? Tell me." The first is formal Kannada written in Roman letters. Use "maga" only if the user talks that way.
