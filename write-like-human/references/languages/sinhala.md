# Sinhala

Rewrite Sinhala so it sounds like a person wrote it, in the style the user chose.

## When this applies

- The text is in Sinhala, in Sinhala script or in Roman script ("Singlish" chat writing).
- The user asks for a translation into Sinhala (also load `translate-humanize.md`).
- For Sinhala mixed with English, also load `mixed-language.md`.

## What stays the same

- Language and script. Sinhala stays Sinhala. Sinhala script stays Sinhala script, Roman stays Roman. Never translate unless asked.
- The register. Sinhala has a big gap between written Sinhala (used in letters, notices, news) and spoken Sinhala (used in chats and between friends). Keep the one the user chose. Do not turn a WhatsApp message into formal written Sinhala, and do not make an official letter chatty.
- Forms of address: ඔබ, ඔයා, තමුන්නාන්සේ, or a name and title. Keep the user's choice.
- Names, numbers, dates, amounts, and places.

## AI tells in Sinhala

- Formal written Sinhala in a casual message, for example "ඔබ" and written verb endings like "යමු" or "කරමි" in a chat to a friend, where people use "ඔයා" and spoken endings.
- Word for word English phrasing: "මම බලාපොරොත්තු වෙනවා මේ පණිවිඩය ඔබව හොඳ සෞඛ්‍යයෙන් සොයා ගනී කියලා".
- Mixing written and spoken verb forms in the same text.
- Starting every sentence with "මම" or "ඔබ", where Sinhala often leaves the subject out.
- Long noun chains copied from English.

## Steps

1. Decide whether the text is written Sinhala or spoken Sinhala, and keep it.
2. Replace translated phrases with how a Sinhala speaker would say them.
3. Make the verb forms consistent with the register.
4. Cut repeated pronouns.
5. Check names, numbers, and dates are unchanged.

## Output

The rewritten Sinhala text, then a short **What I changed** list in the language the user is using with you. Describe the changes in plain words, without word-by-word English glosses of the rewritten text.

## Example

Before (to a friend): "ඔබ හෙට පැමිණෙන්නේද යන්න කරුණාකර දන්වන්න."

After: "ඔයා හෙට එනවද? කියන්න."

Gloss: "Are you coming tomorrow? Let me know." The first uses formal written Sinhala ("ඔබ", "පැමිණෙන්නේද", "කරුණාකර දන්වන්න") that reads like a notice. The rewrite is how people talk to a friend.
