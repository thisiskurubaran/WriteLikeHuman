# Swahili

Rewrite Swahili so it sounds like a person wrote it, in the register the user chose.

## When this applies

- The text is in Swahili (Kiswahili).
- The user asks for a translation into Swahili (also load `translate-humanize.md`). Ask who the reader is if it is not clear.
- For Swahili mixed with English, also load `mixed-language.md`.

## What stays the same

- Language. Swahili stays Swahili. Never translate unless asked.
- Register. Standard Swahili (Kiswahili sanifu) is right for official letters, school, and news. Everyday Swahili is fine for friends and family. Keep what the user chose.
- Sheng. Use Sheng (Nairobi street slang mixing Swahili and English) only if the user already writes in it. Never add it.
- Regional words. Kenyan and Tanzanian Swahili differ a little. Keep the user's words.
- Names, numbers, dates, amounts, and places. Keep the user's currency style (KSh 1,500 or TSh 15,000).

## AI tells in Swahili

- Literal English openers: "Natumaini barua pepe hii inakukuta ukiwa na afya njema." Swahili greetings start with "Habari", "Shikamoo" for elders, or a simple "Hujambo".
- English word order with Swahili words, so noun classes and agreement come out wrong.
- Very formal, bookish words in a message to a friend.
- English words where an everyday Swahili word is normal, or the reverse: forcing a rare Swahili word where people use the English one.
- The same sentence shape repeated.

## Steps

1. Note the register and region, and keep them.
2. Replace translated openers with natural Swahili greetings.
3. Check noun class agreement in every sentence you touch.
4. Use everyday words in casual writing. Vary sentence length.
5. Check names, numbers, and dates are unchanged.

## Output

The rewritten Swahili text, then a short **What I changed** list in the language the user is using with you.

## Example

Before: "Natumaini ujumbe huu unakukuta ukiwa na afya njema. Mkutano umehamishwa hadi Jumatatu."

After: "Habari Amina, mkutano umesogezwa hadi Jumatatu."

Gloss: The first version translates "I hope this message finds you in good health. The meeting has been moved to Monday." The rewrite greets Amina the usual way and keeps Monday.
