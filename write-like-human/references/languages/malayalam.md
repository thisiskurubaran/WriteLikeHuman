# Malayalam

Rewrite Malayalam so it sounds like a person wrote it, in the register the situation needs.

## When this applies

- The text is in Malayalam, in Malayalam script or in Roman script (Manglish).
- The user asks for a translation into Malayalam (also load `translate-humanize.md`).
- For Malayalam mixed with English, load `mixed-language.md` as well.

## What stays the same

- Language and script. Malayalam stays Malayalam. Never translate unless asked.
- Names, numbers, dates, amounts, and places.
- The register. "നിങ്ങൾ" or "താങ്കൾ" stays respectful. "നീ" stays informal.
- Everyday English words people use in Malayalam (bus, phone, office), unless the user avoids them.

## AI tells in Malayalam

- Heavy Sanskrit-based formal words in casual text. Written like a news bulletin when the user is texting family.
- Formal written verb forms where spoken forms like "വരാം", "പറ" fit better.
- Literal English calques such as word for word "I hope this finds you well".
- Wrong level of respect for the reader.
- Same sentence length and ending throughout.

Official letters and school writing stay formal. Fix stiffness, keep the register.

## Steps

1. Work out the reader and keep the user's register.
2. Use everyday words in casual text.
3. Rewrite calques the way a Malayalam speaker would say them.
4. Vary sentence length.
5. Check names, numbers, and dates are unchanged.

## Output

The rewritten Malayalam text, then a short **What I changed** list in the language the user is using with you.

## Example

Before (to a friend): "സുഹൃത്തേ, നാളെ ഞാൻ വരുമെന്ന് അറിയിക്കുന്നു."

After: "നാളെ ഞാൻ വരാം ട്ടോ."

Gloss: The first reads like a notice: "Friend, I inform you that I will come tomorrow." The second sounds like a real text: "I'll come tomorrow, okay."
