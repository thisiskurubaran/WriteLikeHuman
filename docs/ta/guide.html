அன்றாட எழுத்து

Email-ஐ robotic இல்லாம மாத்துங்க

இப்படி ஏதாவது சொல்லுங்கஇந்த email-ஐ இயல்பா மாத்துங்க

  1. Email-ஐ Claude chat-ல paste பண்ணுங்க.
  2. என்ன வேணும்னு உங்க வார்த்தைகள்ல சொல்லுங்க, மேல இருக்கும் உதாரணம் மாதிரி.
  3. புது version-ஐ படிங்க, அப்புறம் அதுக்கு கீழே இருக்கும் சின்ன "What I changed" list-ஐ.
  4. தொனி மாறணுமா? "கொஞ்சம் அன்பா" இல்லன்னா "கொஞ்சம் formal-ஆ" னு சொல்லுங்க.

பெயர்கள், தேதிகள், தொகைகள் நீங்க எழுதின மாதிரியே இருக்கும்.

அனுப்பும் முன் message-ஐ check பண்ணுங்க

இப்படி ஏதாவது சொல்லுங்கஅனுப்பறதுக்கு முன்னாடி இதை check பண்ணுங்க

  1. Message-ஐ paste பண்ணுங்க, நீங்க பதில் சொல்லும் message இருந்தா அதையும்.
  2. அனுப்பும் முன் check பண்ண சொல்லுங்க.
  3. சின்ன list கிடைக்கும்: விட்டுப்போன attachment, தேதியோட பொருந்தாத கிழமை, பதில் சொல்லாத கேள்வி, மீதம் இருக்கும் [name].
  4. சரிசெய்யணும்னா "இதையெல்லாம் சரிபண்ணுங்க" னு சொல்லுங்க.

கஷ்டமான message-க்கு பதில் சொல்லுங்க

இப்படி ஏதாவது சொல்லுங்கDeposit பத்தி house owner-க்கு மரியாதையா பதில் எழுதுங்க

  1. வந்த message-ஐ paste பண்ணி, நீங்க என்ன சொல்லணும்னு சொல்லுங்க.
  2. அமைதியான, தெளிவான ஒரு பதில் கிடைக்கும்.
  3. கொஞ்சம் கண்டிப்பா இல்லன்னா மென்மையா வேணும்னா சொல்லுங்க. ஒப்பிட சரியா ரெண்டு version-ம் கேட்கலாம்.

Slack, Teams, Google Chat message எழுதுங்க

இப்படி ஏதாவது சொல்லுங்கRelease Thursday-க்கு மாறுதுன்னு team-க்கு Slack message எழுதுங்க

  1. என்ன சொல்லணும் இல்லன்னா கேட்கணும், யாருக்குன்னு சொல்லுங்க: ஒரு channel, உங்க lead, இல்லன்னா ஒரு thread.
  2. இல்லன்னா உங்க draft-ஐ paste பண்ணுங்க, நீங்க பதில் சொல்லும் thread-ஐயும்.
  3. முக்கிய விஷயம் முதல் வரியிலேயே இருக்கற சின்ன message கிடைக்கும், paste பண்ண தயார்.
  4. "Hope you're doing well", "Kind regards" மாதிரி email பழக்கங்கள் இருக்காது. வேணும்னா கொஞ்சம் casual-ஆ இல்லன்னா polite-ஆ கேளுங்க.

பெயர்கள், @mentions, ticket numbers, தேதிகள் நீங்க கொடுத்த மாதிரியே இருக்கும். நீங்க கொடுக்காத வாக்குறுதி எதையும் சேர்க்காது.

ஒரு message எப்படி இருக்குன்னு புரிஞ்சுக்கோங்க

இப்படி ஏதாவது சொல்லுங்கBoss அனுப்பின இந்த message எப்படி இருக்கு?

  1. உங்களுக்கு வந்த message-ஐ paste பண்ணுங்க.
  2. மேல இருக்கற மாதிரி அது எப்படி இருக்குன்னு கேளுங்க.
  3. வார்த்தைகளை மட்டும் வச்சு தொனியை அமைதியா விளக்கும். அவங்க மனசுல என்ன நினைக்கறாங்கன்னு ஊகிக்காது.
  4. பதில் வேணும்னா "பதில் எழுத உதவுங்க"ன்னு சொல்லுங்க.

அதிக salary, விலை, வாடகை பத்தி பேசுங்க

இப்படி ஏதாவது சொல்லுங்கஅதிக salary கேட்க உதவுங்க, offer 9 lakh, நான் 11 எதிர்பார்த்தேன்

  1. Offer, உங்களுக்கு எவ்வளவு வேணும், உங்க உண்மையான காரணங்கள், இதை சொல்லுங்க.
  2. அனுப்பவோ பேசவோ ஒரு சின்ன, மரியாதையான message கிடைக்கும்.
  3. வேணும்னா கொஞ்சம் உறுதியா இல்லன்னா மென்மையா மாத்த சொல்லுங்க.

நீங்க கொடுத்த எண்களையும் காரணங்களையும் மட்டும் பயன்படுத்தும். வேற offer-ஓ சாதனையோ சேர்க்காது.

என்ன கேட்கணும்னு தெரியலையா? சட்டுனு options-ல தேர்ந்தெடுங்க

இப்படி ஏதாவது சொல்லுங்கஇதுக்கு கொஞ்சம் உதவுங்க

  1. Text-ஐ paste பண்ணுங்க இல்லன்னா file-ஐ attach பண்ணுங்க, கூடவே மேல இருக்கற மாதிரி ஒரு சின்ன message, இல்லன்னா எதுவுமே வேணாம்.
  2. 2 முதல் 4 சின்ன, எண் போட்ட options கிடைக்கும், உதாரணமா "பதில் எழுது" இல்லன்னா "அனுப்பும் முன் check பண்ணு". Claude Code-ல ஒன்னை tap பண்ணலாம்.
  3. ஒரு எண்ணை reply பண்ணுங்க, இல்லன்னா என்ன வேணும்னு உங்க வார்த்தைகள்ல சொல்லுங்க.
  4. நீங்க தேர்ந்தெடுக்கற வரை எதுவும் மாறாது.

"இதை கொஞ்சம் friendly-ஆ மாத்துங்க" மாதிரி தெளிவான கேள்விக்கு options வராது, நேரா வேலை நடக்கும்.

Files

Word file-ஐ சரிசெய்யுங்க, காரணம் comments-ல

இப்படி ஏதாவது சொல்லுங்கஇந்த Word file-ஐ humanize பண்ணி, ஒவ்வொரு மாற்றத்துக்கும் காரணத்தை comment-ல எழுதுங்க

  1. .docx file-ஐ இணையுங்க.
  2. உதாரணம் மாதிரி சரிசெய்ய சொல்லுங்க. Comment வேணாம்னா அந்த பகுதியை விட்டுடுங்க.
  3. -humanized-ல முடியும் புது copy கிடைக்கும். Fonts, tables, lists அப்படியே இருக்கும்.
  4. ஒவ்வொரு மாற்றத்துக்கும் margin-ல ஏன்னு ஒரு சின்ன note இருக்கும். வேணும்னா tracked changes கேளுங்க.

உங்க original file ஒருபோதும் மாற்றப்படாது.

Form நிரப்புங்க

இப்படி ஏதாவது சொல்லுங்கஎன் விவரங்களோட இந்த visa form-ஐ நிரப்புங்க

  1. நிரப்பக்கூடிய PDF இல்லன்னா Word form-ஐ இணையுங்க.
  2. உங்க விவரங்களை chat-ல எந்த வரிசையிலும் கொடுங்க.
  3. நிரப்பின copy கிடைக்கும், நிரப்ப முடியாதவற்றோட list-ம்.
  4. ஒவ்வொரு field-ஐயும் நீங்களே check பண்ணி, நீங்களே sign பண்ணுங்க.

ID number, பிறந்த தேதி, முகவரி எதையும் ஊகிச்சு நிரப்பாது, உங்களுக்கு பதிலா declaration-ல tick பண்ணாது.

Template நிரப்புங்க

இப்படி ஏதாவது சொல்லுங்கஇந்த கடிதத்தோட என் company letterhead-ஐ நிரப்புங்க

  1. உங்க Word இல்லன்னா PowerPoint template-ஐ இணையுங்க.
  2. அதுல என்ன வரணுமோ அதை paste பண்ணுங்க இல்லன்னா சொல்லுங்க.
  3. நிரப்பின copy கிடைக்கும், template-ஓட look அப்படியே.
  4. நீங்க கொடுக்காதது தெளிவான [blank]-ஆ நிரப்புறதுக்கு விடப்படும்.

Notes-ல இருந்து slides செய்யுங்க

இப்படி ஏதாவது சொல்லுங்கஇந்த notes-ல இருந்து team meeting-க்கு 5 slides செய்யுங்க

  1. உங்க notes-ஐ paste பண்ணுங்க, பயன்படுத்த வேண்டிய எண்களோட.
  2. எத்தனை slides வேணும்னு சொல்லுங்க, இல்லன்னா Claude-ஐ தேர்ந்தெடுக்க விடுங்க.

நீளமான thesis, manual, report-ஐ சரி பண்ணுங்க

Architecture இல்லன்னா folder structure-ஐ விளக்குங்க

இப்படி ஏதாவது சொல்லுங்கபுது teammate-க்கு எங்க folder structure-ஐ விளக்குங்க

  1. Claude Code-ல project-ஐ திறந்து கேளுங்க. மத்த இடங்கள்ல folder tree (tree -L 2) இல்லன்னா அதோட screenshot-ஐ paste பண்ணுங்க.
  2. Folder structure-க்கு tree கிடைக்கும், கூடவே ஒவ்வொரு folder-க்கும் ஒரு வரி: அதுல என்ன இருக்கு, எப்போ edit பண்ணணும்.

  4. Decision record (ADR)-க்கு உங்க முடிவையும் காரணங்களையும் சொல்லுங்க. சுருக்கமான Context, Decision, Consequences sections கிடைக்கும்.

Folders, services-ஓட உண்மையான பெயர்களை பயன்படுத்தும், உங்க code-ல இல்லாத பகுதிகளை சேர்க்காது. Code files-ஐ ஒருபோதும் move பண்ணாது, புதுசா உருவாக்காது.

Code-ஐ தொடாம code comments-ஐ சரி பண்ணுங்க

இப்படி ஏதாவது சொல்லுங்கbilling.py-ல comments-ஐ சரி பண்ணுங்க, code-ஐ தொடாதீங்க

  1. File-ஐ attach இல்லன்னா paste பண்ணுங்க, இல்லன்னா Claude Code-ல project-ஐ திறந்து கேளுங்க.
  2. Comments, docstrings மட்டும் மறுபடி எழுதப்படும், பெரும்பாலும் code ஏன் அப்படி செய்யுதுன்னு விளக்க.
  3. ஒரு script ஒவ்வொரு comment-ஐயும் அதோட இடத்துலயே திரும்ப வைக்கும், code கொஞ்சம் மாறினாலும் save பண்ண மறுக்கும்.
  4. -humanized-ல முடியற புது copy கிடைக்கும் (git repo-ல file அங்கேயே edit ஆகும்), கூடவே நீக்கலாம்னு தோணும் comments-ஓட list.

License headers, noqa மாதிரி tool directives, comment பண்ணின code, TODOs, @param பெயர்கள் அப்படியே இருக்கும்.

தெளிவான error messages, app text எழுதுங்க

இப்படி ஏதாவது சொல்லுங்கஇந்த error messages-ஐ கொஞ்சம் friendly-ஆ மாத்துங்க

  1. Messages, button labels, இல்லன்னா translation file-ஐ (en.json மாதிரி) paste பண்ணுங்க, code என்ன செய்யுதுன்னு தெளிவா இல்லன்னா சொல்லுங்க.
  2. ஒவ்வொரு error message-உம் என்ன ஆச்சு, இப்போ என்ன பண்ணலாம்னு சொல்லும்.
  3. Buttons அவை என்ன செய்யும்னு சொல்லும், காலியான screens அடுத்து என்ன பண்ணணும்னு சொல்லும்.
  4. Translation file-ல English values மட்டும் மாறும். Keys, {name} மாதிரி placeholders அப்படியே இருக்கும்.

API docs-உம் பண்ணலாம்: endpoint-ஐ paste பண்ணுங்க, எளிய description, parameter table, உங்க உண்மையான field names-ஓட ஒரு example கிடைக்கும்.
