உருவாக்கு

WriteLikeHuman எளிமையான, மனித வார்த்தைகளில் content எழுதும். File-ஐ Claude தன் file tools மூலம் உருவாக்கும்.

    Word documents

    PDF

Developers-க்கு

உங்க code-ஐ சுத்தி இருக்கும் வார்த்தைகளை எழுதும். Code-ஐ தொடவே தொடாது.

README, commit messages, pull requests, architecture docs, API docs, error messages, code comments. Claude Code-ல பயன்படுத்துங்க, இல்லன்னா text-ஐ Claude-ஓட எந்த chat-லயும் paste பண்ணுங்க.

உங்க வார்த்தைகள்ல கேளுங்க

Text-ஐ paste பண்ணுங்க, இல்லன்னா project-ஐ திறந்து Claude Code-ல கேளுங்க.

  • இந்த project-க்கு README எழுதித் தாங்க
  • என் staged changes-க்கு commit message எழுதுங்க
  • புது teammate-க்கு எங்க folder structure-ஐ விளக்குங்க
  • இந்த error messages-ஐ கொஞ்சம் friendly-ஆ மாத்துங்க
  • billing.py-ல comments-ஐ சரி பண்ணுங்க, code-ஐ தொடாதீங்க

எது பத்திரமா இருக்கும்

மக்கள் படிக்கும் வார்த்தைகள் மட்டும் மாறும்.

  • Commands, code blocks, file paths, version numbers எழுதின மாதிரியே இருக்கும்
  • Translation keys, {name} மாதிரி placeholders தொடப்படவே மாட்டாது
  • Code comments-ஐ ஒரு script மாத்தும், code கொஞ்சம் மாறினாலும் அது save பண்ணாது
  • Git repo-ல file அங்கேயே edit ஆகும், git diff அல்லது git checkout வச்சு மாற்றத்தை எப்படி பார்க்கலாம், undo பண்ணலாம்னு சொல்லும்
  • நீங்க சொல்லாம எதுவும் commit, push ஆகாது

இது இலவசமா?

ஆமா. WriteLikeHuman MIT license-ல இலவசம், open source. Skills கிடைக்கிற Claude account மட்டும் வேணும்.

என் document கெட்டுப் போயிடுமா?

வார்த்தைகள மட்டும் மாத்தும், layout-ஐ இல்ல. Fonts, tables, lists, formulas இடம் மாறாது, "-humanized" னு பெயருள்ள புது copy எப்பவும் கிடைக்கும், original-க்கு ஒண்ணும் ஆகாது.

Phone-ல வேலை செய்யுமா?

ஆமா. Claude website அல்லது desktop app-ல ஒருமுறை upload பண்ணுங்க, அப்புறம் அதே account-ல Claude phone app-ல பயன்படுத்துங்க.

இது வேலை செய்யல, இப்போ என்ன செய்வது?

உங்க message-ஐ "Use WriteLikeHuman to..." னு ஆரம்பிங்க. அப்பவும் இல்லைன்னா Customize > Skills-ல switch on-ஆ இருக்கான்னு பாருங்க.

இதை மேம்படுத்த நான் உதவலாமா?
