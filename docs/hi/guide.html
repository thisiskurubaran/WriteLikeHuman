रोज़ की लिखाई

Email को कम robotic बनाएँ

कुछ ऐसा लिखेंइस email को थोड़ा natural बना दो

  1. Email को Claude के chat में paste कीजिए।
  2. अपने शब्दों में बताइए क्या चाहिए, जैसे ऊपर का उदाहरण।
  3. नया version पढ़िए, फिर उसके नीचे छोटी "What I changed" list।
  4. Tone बदलना है? कहिए "थोड़ा और warm" या "थोड़ा formal"।

नाम, तारीखें और रकम बिल्कुल वैसी रहती हैं जैसी आपने लिखी थीं।

भेजने से पहले message check करें

कुछ ऐसा लिखेंभेजने से पहले इसे check कर दो

  1. Message paste कीजिए, और जिसका जवाब दे रहे हैं वह भी, अगर है।
  2. भेजने से पहले check करने को कहिए।
  3. आपको छोटी list मिलेगी: छूटा हुआ attachment, तारीख से मेल न खाता दिन, बिना जवाब का सवाल, बचा हुआ [name]।
  4. ठीक करवाना हो तो कहिए "इन्हें ठीक कर दो"।

मुश्किल message का जवाब दें

कुछ ऐसा लिखेंDeposit के बारे में मकान मालिक को बिना रूखे लगे जवाब लिख दो

  1. जो message आया है उसे paste कीजिए और बताइए आप क्या कहना चाहते हैं।
  2. आपको एक शांत, साफ़ जवाब मिलेगा।
  3. थोड़ा सख़्त या नरम चाहिए तो बताइए। तुलना के लिए ठीक दो versions भी माँग सकते हैं।

Slack, Teams या Google Chat message लिखें

कुछ ऐसा लिखेंTeam को Slack message लिख दो कि release अब Thursday को होगा

  1. बताइए क्या कहना या पूछना है, और किसके लिए: कोई channel, आपके lead, या कोई thread।
  2. या अपना draft paste कीजिए, साथ में वह thread जिसका reply कर रहे हैं।
  3. आपको छोटा message मिलेगा, असली बात पहली line में, paste करने के लिए तैयार।
  4. "Hope you're doing well" और "Kind regards" जैसी email वाली आदतें हट जाती हैं। चाहें तो थोड़ा casual या थोड़ा polite करवाइए।

नाम, @mentions, ticket numbers और तारीखें वैसी ही रहती हैं जैसी आपने दीं। जो वादा आपने नहीं किया, वह नहीं जोड़ा जाता।

Message का लहजा समझें

कुछ ऐसा लिखेंBoss का यह message कैसा लग रहा है?

  1. जो message आया है उसे paste कीजिए।
  2. पूछिए कि यह कैसा लग रहा है, जैसे ऊपर।
  3. आपको सिर्फ़ शब्दों के आधार पर लहजे की शांत समझ मिलेगी। यह अंदाज़ा नहीं लगाता कि सामने वाला मन में क्या सोच रहा है।
  4. जवाब चाहिए तो कहिए "जवाब लिखने में मदद करो"।

ज़्यादा salary, कीमत या किराए की बात करें

कुछ ऐसा लिखेंज़्यादा salary माँगने में मदद करो, offer 9 lakh है और मुझे 11 की उम्मीद थी

  1. Offer, आपको कितना चाहिए, और आपकी असली वजहें बताइए।
  2. आपको छोटा, विनम्र message मिलेगा जो आप भेज या बोल सकते हैं।
  3. चाहें तो थोड़ा सख़्त या नरम करवाइए।

यह सिर्फ़ आपके दिए नंबर और वजहें इस्तेमाल करता है। कोई दूसरा offer या उपलब्धि नहीं गढ़ता।

जब पक्का न हो क्या माँगें, तो झटपट options पाएँ

कुछ ऐसा लिखेंइसमें मदद कर दो

  1. Text paste कीजिए या file लगाइए, साथ में ऊपर जैसा छोटा message, या कुछ भी नहीं।
  2. आपको 2 से 4 छोटे, नंबर वाले options मिलेंगे, जैसे "Reply लिखो" या "भेजने से पहले check करो"। Claude Code में आप किसी एक पर tap कर सकते हैं।
  3. नंबर लिखकर जवाब दीजिए, या अपने शब्दों में बताइए क्या चाहिए।
  4. आपके चुनने तक कुछ नहीं बदलता।

साफ़ request, जैसे "इसे थोड़ा friendly बना दो", पर options नहीं आते, सीधे काम होता है।

Files

Word file ठीक करें, वजह comments में

कुछ ऐसा लिखेंइस Word file को humanize करो और हर बदलाव की वजह comment में लिखो

  1. .docx file लगाइए।
  2. उदाहरण की तरह ठीक करने को कहिए। Comment नहीं चाहिए तो वह हिस्सा छोड़ दीजिए।
  3. आपको -humanized वाली नई copy मिलेगी। Fonts, tables और lists वैसे ही रहते हैं।
  4. हर बदलाव के साथ margin में छोटा note होगा कि क्यों बदला। चाहें तो tracked changes माँगिए।

आपकी original file कभी नहीं बदली जाती।

Form भरें

कुछ ऐसा लिखेंमेरी details से यह visa form भर दो

  1. भरने लायक PDF या Word form लगाइए।
  2. अपनी details chat में किसी भी क्रम में दीजिए।
  3. आपको भरी हुई copy मिलेगी, और जो नहीं भर पाया उसकी list।
  4. हर field खुद check कीजिए और sign खुद कीजिए।

यह ID number, जन्म तारीख या पता कभी अंदाज़े से नहीं भरता, और आपकी जगह declaration पर tick नहीं करता।

Template भरें

कुछ ऐसा लिखेंइस letter से मेरा company letterhead भर दो

  1. अपना Word या PowerPoint template लगाइए।
  2. जो उसमें जाना है वह paste कीजिए या बताइए।
  3. आपको भरी हुई copy मिलेगी, template का look वैसा ही।
  4. जो आपने नहीं दिया वह साफ़ [blank] के रूप में भरने के लिए छोड़ा जाता है।

Notes से slides बनाएँ

कुछ ऐसा लिखेंइन notes से team meeting के लिए 5 slides बना दो

  1. अपने notes paste कीजिए, साथ में जो नंबर इस्तेमाल करने हैं।
  2. बताइए कितनी slides चाहिए, या Claude को चुनने दीजिए।
  3. आपको .pptx मिलेगी, slides पर छोटा text और speaker notes में पूरी बात।
  4. Slide के हिसाब से बदलाव माँगिए: "slide 3 का title छोटा करो"।

यह कभी ऐसे आँकड़े, charts या नतीजे नहीं जोड़ता जो आपने नहीं दिए।

Spreadsheet बनाएँ

कुछ ऐसा लिखेंइन खर्चों को notes column वाली sheet में डाल दो

  1. अपनी list paste कीजिए: चीज़ें, रकम, तारीखें।
  2. बताइए कौन से columns चाहिए।
  3. आपको .xlsx मिलेगी, आपके नंबर बिल्कुल वैसे, और totals formulas में ताकि सही रहें।

Google Sheet या Slides deck edit करें

कुछ ऐसा लिखेंमेरी Google Sheet के Remarks column को natural बना दो

  1. Claude को अपने Google account से जोड़िए (Settings, फिर Connectors), अगर अभी तक नहीं जोड़ा।
  2. Sheet या Slides deck का link chat में दीजिए।
  3. Text वहीं ठीक हो जाता है। नंबर, formulas और layout नहीं छेड़े जाते।
  4. Connector नहीं है? .xlsx या .pptx download करके लगाइए, नई copy मिल जाएगी।

लंबी thesis, manual या report ठीक करें

कुछ ऐसा लिखेंमेरी 120 page की thesis की wording ठीक करो, terms एक जैसे रखना

  1. File लगाइए। Word, PDF या LaTeX (.tex), सब चलते हैं।
  2. Claude इसे section दर section ठीक करता है और नामों व terms की list रखता है ताकि वे एक जैसे रहें।
  3. आपको -humanized वाली नई copy मिलेगी, और उन बातों की छोटी note जिन पर वह पक्का नहीं था।
  4. LaTeX में सिर्फ़ text बदलता है। Commands, गणित और citations बिल्कुल वैसे ही रहते हैं।

आपकी आवाज़

अपनी voice profile बनाएँ

कुछ ऐसा लिखेंइन 3 messages से मेरी quick voice profile बना दो

  1. जल्दी शुरुआत के लिए अपने लिखे 3 छोटे messages paste कीजिए।
  2. आपको छोटी profile मिलेगी: आपके वाक्य कितने लंबे होते हैं, कौन से शब्द पसंद हैं, आप कैसे खत्म करते हैं।
  3. इसे note या file में सँभालिए और अगली बार लगाइए: "मेरी voice profile इस्तेमाल करो"।
  4. बाद में और लिखाई जोड़कर इसे बेहतर बनाइए, या "office वाला मैं" और "घर वाला मैं" अलग रखिए।

सिर्फ़ आपकी अपनी लिखाई। यह किसी और की आवाज़ की नकल नहीं करता।

Team की style guide बनाएँ

कुछ ऐसा लिखेंमेरी bakery के messages के लिए style guide बनाने में मदद करो

  1. Style guide माँगिए, या जो पहले से है वह लगाइए।
  2. खाली जगहें भरिए: products के नाम, कौन से शब्द लिखने हैं और कौन से नहीं, आप कैसे sign off करते हैं।
  3. इसे सँभालिए और team के लिए लिखते समय लगाइए।
  4. फिर हर message इसी के हिसाब से होगा, और products के नाम हूबहू रहेंगे।

छोटा कारोबार

Payment reminder भेजें

कुछ ऐसा लिखेंInvoice 1043, Rs 18,500, due 5 March के लिए विनम्र reminder लिख दो

  1. Invoice number, रकम और due date दीजिए।
  2. बताइए यह पहला reminder है या दोबारा।
  3. आपको email या WhatsApp के लिए छोटा, विनम्र message मिलेगा, बाद वाले reminders में थोड़ा सख़्त।
  4. रकम, तारीखें और invoice number बिल्कुल वैसे रहते हैं जैसे आपने दिए।

Customer को जवाब दें

कुछ ऐसा लिखेंइस customer को जवाब लिख दो जिसका order देर से पहुँचा

  1. Customer का message और बातें paste कीजिए: order number, क्या गड़बड़ हुई, आप क्या करेंगे।
  2. आपको ऐसा जवाब मिलेगा जो एक बार माफ़ी माँगता है, हल बताता है, और आगे क्या होगा वह बताता है।
  3. यह सिर्फ़ वही वादा करता है जो आपने कहा कि आप करेंगे।

Out-of-office reply लगाएँ

कुछ ऐसा लिखेंOut-of-office reply लिख दो, मैं 10 से 14 March तक बाहर हूँ, Ravi से संपर्क करें

  1. तारीखें दीजिए और बताइए किससे संपर्क करें।
  2. बताइए यह कहाँ के लिए है: email, WhatsApp Business का away message, या दोनों।
  3. आपको छोटा reply मिलेगा जो आप paste कर सकते हैं। चाहिए तो email signature भी माँगिए।

लोगों की list को personal messages भेजें

कुछ ऐसा लिखेंइस sheet की हर row के लिए नाम के साथ एक Diwali message बना दो

  1. नामों वाली spreadsheet लगाइए, और कोई detail जो इस्तेमाल करनी है, जैसे order या शहर।
  2. Message एक बार लिखिए या बताइए।
  3. आपको हर row के लिए एक draft वाली file मिलेगी। कुछ भी भेजा नहीं जाता।
  4. हर draft खुद WhatsApp या email में copy कीजिए।

सिर्फ़ उन लोगों के लिए जिन्हें आप पहले से जानते हैं, जैसे customers या परिवार। यह bulk marketing या spam नहीं लिखता।

हिंदी या तमिल लिपि में लिखें

कुछ ऐसा लिखेंइसे Hindi script में लिख दो: kal subah 10 baje milte hain

  1. अंग्रेज़ी अक्षरों में लिखी अपनी Hinglish या Tanglish paste कीजिए।
  2. इसे हिंदी (देवनागरी) या तमिल लिपि में माँगिए।
  3. आपको वही शब्द उस लिपि में मिलेंगे। कुछ भी अनुवाद नहीं होता।
  4. नाम और अंग्रेज़ी शब्द check कीजिए, क्योंकि कुछ एक से ज़्यादा तरह लिखे जा सकते हैं।

हिंदी और तमिल के साथ तेलुगु, कन्नड़, मलयालम, बांग्ला, मराठी और गुजराती में भी चलता है।

Images के लिए alt text लिखें

कुछ ऐसा लिखेंइन 3 product photos के लिए alt text लिख दो

  1. Images लगाइए।
  2. बताइए ये कहाँ जाएँगी: Instagram post, website या slides।
  3. हर एक के लिए छोटा, सीधा विवरण मिलेगा।
  4. यह सिर्फ़ वही बताता है जो दिख रहा है, और कभी अंदाज़ा नहीं लगाता कि लोग कौन हैं।

Easy Read या dyslexia friendly बनाएँ

कुछ ऐसा लिखेंइस Word file को dyslexia friendly बना दो

  1. File लगाइए या text paste कीजिए।
  2. छोटी, आसान lines और तस्वीरों के सुझाव के लिए Easy Read माँगिए, या साफ़ layout के लिए dyslexia friendly।
  3. Dyslexia friendly में हर शब्द वही रहता है, सिर्फ़ font, spacing और alignment बदलते हैं। आपको -readable वाली नई copy मिलेगी।
  4. Easy Read आसान शब्दों में दोबारा लिखता है, इसलिए देख लीजिए कि कोई ज़रूरी बात छूटी तो नहीं।

Developers के लिए

README लिखें या ठीक करें

कुछ ऐसा लिखेंइस project का README लिख दो

  1. Claude Code में project खोलकर पूछिए। बाकी जगह अपना README paste कीजिए और बताइए project क्या करता है।
  2. आपको छोटी शुरुआत मिलेगी कि यह क्या है और किसके लिए है, फिर install, quick start और usage।
  3. Install steps में आपके repo के असली commands होते हैं। कोई step न मिले तो अंदाज़े की जगह साफ़ TODO मिलता है।
  4. हर heading पर emoji, badges की दीवार और sales वाले शब्द हटा दिए जाते हैं।

Commands, code blocks, paths और version numbers बिल्कुल वैसे ही रहते हैं। जो feature project में नहीं है, वह कभी नहीं जोड़ा जाता।

Commit message या PR description लिखें

कुछ ऐसा लिखेंमेरे staged changes के लिए commit message लिख दो

  1. Claude Code में बस पूछिए, वह आपके staged changes पढ़ लेता है। बाकी जगह diff या बदलावों की list paste कीजिए।
  2. आपको करीब 72 characters से छोटी summary line मिलेगी, और ज़रूरत हो तो एक-दो lines कि क्यों।
  3. PR के लिए: क्या बदला, क्यों बदला और कैसे check करें, और repo में PR template हो तो उसी के हिसाब से।
  4. यह आपके repo का style अपनाता है, जैसे fix(login): या ticket prefix, और आपके कहे बिना commit नहीं करता।

यह सिर्फ़ वही लिखता है जो diff में है। Tests जोड़े गए या pass हुए, यह तभी कहता है जब सच में ऐसा हुआ हो।

Architecture या folder structure समझाएँ

कुछ ऐसा लिखेंनए teammate के लिए हमारा folder structure समझा दो

  1. Claude Code में project खोलकर पूछिए। बाकी जगह folder tree (tree -L 2) या उसका screenshot paste कीजिए।
  2. Folder structure के लिए आपको tree मिलेगा, और हर folder पर एक line: उसमें क्या है और उसे कब edit करना है।
  3. Architecture doc में मुख्य हिस्से, हर हिस्सा किससे बात करता है, और एक असली request शुरू से आखिर तक।
  4. Decision record (ADR) के लिए अपना फ़ैसला और वजहें बताइए। आपको छोटे Context, Decision और Consequences sections मिलेंगे।

यह folders और services के असली नाम इस्तेमाल करता है, और ऐसे हिस्से नहीं गढ़ता जो आपके code में नहीं हैं। Code files को कभी move या create नहीं करता।

Code को छुए बिना code comments ठीक करें

कुछ ऐसा लिखेंbilling.py के comments ठीक कर दो, code मत छूना

  1. File लगाइए या paste कीजिए, या Claude Code में project खोलकर पूछिए।
  2. सिर्फ़ comments और docstrings दोबारा लिखे जाते हैं, ज़्यादातर यह समझाने के लिए कि code कोई काम क्यों करता है।
  3. एक script हर comment को उसकी जगह वापस रखती है, और code ज़रा भी बदले तो save करने से मना कर देती है।
  4. आपको -humanized वाली नई copy मिलेगी (git repo में file वहीं edit होती है), साथ में उन comments की list जिन्हें हटाना ठीक रहेगा।

License headers, noqa जैसे tool directives, comment किया हुआ code, TODOs और @param के नाम वैसे ही रहते हैं।

साफ़ error messages और app text लिखें

कुछ ऐसा लिखेंइन error messages को थोड़ा friendly बना दो

  1. Messages, button labels या translation file (जैसे en.json) paste कीजिए, और साफ़ न हो तो बताइए code क्या करता है।
  2. हर error message बताता है कि क्या हुआ और अब सामने वाला क्या कर सकता है।
  3. Buttons बताते हैं कि वे क्या करते हैं, और खाली screens बताती हैं कि आगे क्या करें।
  4. Translation file में सिर्फ़ English values बदलती हैं। Keys और {name} जैसे placeholders बिल्कुल वैसे रहते हैं।

API docs भी बनते हैं: endpoint paste कीजिए, आपको सीधा description, parameter table और आपके असली field names वाला example मिलेगा।
