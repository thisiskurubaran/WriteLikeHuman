Code के आस-पास के शब्दों में मदद, अधूरी request पर झट से चुनने वाले options, और work chat के messages।

  • झटपट optionsबस "help with this" कहिए और 2 से 4 छोटे options में से चुनिए। साफ़ request पर सीधे काम शुरू।
  • README और docsसीधी शुरुआत और असली install steps, हर command बिल्कुल वैसी ही।
  • Commit messages और PRsछोटी summary line और वजह, सिर्फ़ उसी के आधार पर जो आपके diff में है।
  • Architecture और folder structureआपका project कैसे जुड़ा है, असली folder नामों के साथ। Decision records भी।
  • Code comments, code वैसा हीसाफ़ comments और docstrings। Code ज़रा भी बदले तो script save नहीं करती।

Files दीजिए, files लीजिए

नई files बनाइए, या अपनी files ठीक कराइए

Word document, PDF या spreadsheet माँगिए, पहले draft से ही शब्द सहज लगेंगे। या अपनी file भेजिए, शब्द सुधरकर वापस आएँगे और layout वैसा ही रहेगा।

नई file बनाइए

बनाएँ

WriteLikeHuman सीधे, इंसानी शब्दों में content लिखती है। File, Claude अपने file tools से बनाता है।

  • DOCX

    Word documents

    Letter, cover letter, report और notice, खोलने और edit करने के लिए तैयार।

    मेरी छुट्टी की चिट्ठी Word file में लिख दोleave-letter.docx
  • PDF

    PDF

    Print के लिए तैयार notice, invitation और handout।

    इस society notice का print करने लायक PDF बना दोwater-cut-notice.pdf
  • XLSX

    Spreadsheets

    साफ़ headings और notes वाले trackers और lists। आपके नंबर बिल्कुल वैसे ही जाते हैं जैसे आपने दिए।

    इन खर्चों को notes column वाली sheet में डाल दोtrip-expenses.xlsx

अपनी file edit कराइए

Edit

सिर्फ़ शब्द बदलते हैं। हर edit की हुई file नई copy बनकर आती है, तो original सुरक्षित रहती है।

  • DOCX

    Word documents

    File के अंदर ही दोबारा लिखा जाता है। Fonts, tables, headers और lists वैसे ही रहते हैं, चाहें तो tracked changes के साथ।

    मेरा resume natural बना दो, formatting मत छेड़नाresume-humanized.docx
  • PDF

    PDF

    हर page पढ़कर आपको edit करने लायक Word copy देती है, क्योंकि PDF को सीधे सुरक्षित तरीके से edit नहीं किया जा सकता। Scan किए pages बताए जाते हैं।

    इस PDF report के शब्द ठीक कर दोreport-humanized.docx
  • XLSX

    Spreadsheets

    सिर्फ़ text cells, notes और comments छुए जाते हैं। नंबर, तारीखें और formulas कभी नहीं बदलते।

    Remarks column ठीक कर दो, नंबर मत छूनाbudget-humanized.xlsx

PowerPoint slides और speaker notes, Google Docs, Pages और Keynote, web pages और subtitle files के साथ भी चलती है। Claude में Code execution and file creation चालू होना चाहिए।

Developers के लिए

आपके code के आस-पास के शब्द लिखती है। Code को छूती तक नहीं।

README, commit messages, pull requests, architecture docs, API docs, error messages और code comments। Claude Code में इस्तेमाल कीजिए, या text को Claude के किसी भी chat में paste कीजिए।

अपने शब्दों में पूछिए

Text paste कीजिए, या project खोलकर Claude Code में पूछिए।

  • इस project का README लिख दो
  • मेरे staged changes के लिए commit message लिख दो
  • नए teammate के लिए हमारा folder structure समझा दो
  • इन error messages को थोड़ा friendly बना दो
  • billing.py के comments ठीक कर दो, code मत छूना

क्या सुरक्षित रहता है

सिर्फ़ वे शब्द बदलते हैं जो लोग पढ़ते हैं।

  • Commands, code blocks, file paths और version numbers बिल्कुल वैसे ही रहते हैं
  • Translation keys और {name} जैसे placeholders को छुआ तक नहीं जाता
  • Code comments एक script बदलती है, और code ज़रा भी बदले तो वह save ही नहीं करती
  • Git repo में file वहीं edit होती है, और आपको बताया जाता है कि git diff या git checkout से बदलाव कैसे देखें या वापस लें
  • आपके कहे बिना कुछ भी commit या push नहीं होता

  1. 01Download

  2. 02चालू करें

सवाल-जवाब

आम सवाल

ज़्यादा जानकारी हिंदी install guide में है, English में भी।

क्या यह free है?

हाँ। WriteLikeHuman MIT license के तहत free और open source है। बस ऐसा Claude account चाहिए जिसमें skills मिलती हों।

कहीं मेरा document बिगड़ तो नहीं जाएगा?

यह शब्द बदलती है, layout नहीं। Fonts, tables, lists और formulas अपनी जगह रहते हैं, और आपको हमेशा "-humanized" नाम की नई copy मिलती है, तो original को कुछ नहीं होता।

क्या यह phone पर चलेगी?

हाँ। एक बार Claude website या desktop app पर upload कीजिए, फिर उसी account से Claude phone app में इस्तेमाल कीजिए।

यह चली ही नहीं, अब क्या करूँ?

अपना message "Use WriteLikeHuman to..." से शुरू कीजिए। फिर भी न चले तो Customize > Skills में देखिए कि switch चालू है।

क्या मैं इसे बेहतर बनाने में मदद कर सकता हूँ?

हाँ, खासकर अगर आप इनमें से कोई भाषा बोलते हैं। किसी भी language guide को अभी तक native speaker ने check नहीं किया है। सुधार सुझाइए या contributing guide पढ़िए।
