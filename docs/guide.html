Everyday writing

Make an email sound less robotic

Say something likeMake this email sound less robotic

  1. Paste the email into a chat with Claude.
  2. Say what you want in your own words, like the example.
  3. Read the new version, then the short "What I changed" list under it.
  4. Want a different tone? Say "a bit warmer" or "more formal".

Names, dates, and amounts stay exactly as you wrote them.

Check a message before sending it

Say something likeCheck this before I send it

  1. Paste the message, plus the one you're replying to if there is one.
  2. Ask for a check before you send.
  3. You get a short list: a missing attachment, a weekday that doesn't match the date, an unanswered question, a leftover [name].
  4. Say "fix these" if you want them fixed.

Reply to a tricky message

Say something likeReply to my landlord about the deposit without sounding rude

  1. Paste the message you got and say what you want to say back.
  2. You get one reply, calm and clear.
  3. If you want it firmer or softer, say so. You can also ask for exactly two versions to compare.

Write a Slack, Teams, or Google Chat message

Say something likeWrite a Slack message telling my team the release moves to Thursday

  1. Say what you want to tell or ask, and who it's for: a channel, your lead, or a thread.
  2. Or paste your draft, plus the thread you're replying to.
  3. You get a short message with the point in the first line, ready to paste.
  4. Email habits like "Hope you're doing well" and "Kind regards" are left out. Ask for it more casual or more polite if you like.

Names, @mentions, ticket numbers, and dates stay as you gave them. It won't add promises you didn't make.

Understand how a message sounds

Say something likeHow does this message from my boss sound?

  1. Paste the message you got.
  2. Ask how it sounds, like the example.
  3. You get a calm reading of the tone, based only on the words. It won't guess what the person secretly means.
  4. Say "help me reply" if you want a reply next.

Ask for a better salary, price, or rent

Say something likeHelp me ask for a higher salary, the offer is 9 lakh and I was hoping for 11

  1. Give the offer, the number you want, and your real reasons.
  2. You get a short, polite message you can send or say.
  3. Ask for it firmer or softer if you like.

It uses only the numbers and reasons you give. It won't invent other offers or achievements.

Get quick choices when you're not sure what to ask

Say something likehelp with this

  1. Paste the text or attach the file, with a short message like the example, or none at all.
  2. You get 2 to 4 short numbered choices, like "Write a reply" or "Check it before you send". In Claude Code you can tap one.
  3. Reply with a number, or say what you want in your own words.
  4. Nothing changes until you pick.

Clear requests, like "make this friendlier", skip the options and go straight to the work.

Files

Fix a Word file, with the reasons in comments

Say something likeHumanize this Word file and explain each change in a comment

  1. Attach the .docx file.
  2. Ask for the fix, like the example. Leave out the comment part if you don't need it.
  3. You get a new copy ending in -humanized. Fonts, tables, and lists stay the same.
  4. Each change has a short note in the margin saying why. Ask for tracked changes instead if you prefer.

Your original file is never overwritten.

Fill in a form

Say something likeFill this visa form with my details

  1. Attach the fillable PDF or the Word form.
  2. Give your details in the chat, in any order.
  3. You get a filled copy, plus a list of anything it couldn't fill.
  4. Check every field and sign it yourself.

It never guesses ID numbers, dates of birth, or addresses, and never ticks a declaration for you.

Fill a template

Say something likeFill my company letterhead with this letter

  1. Attach your Word or PowerPoint template.
  2. Paste or describe what should go in it.
  3. You get a filled copy with your template's look kept.
  4. Anything you didn't give stays as a clear [blank] to fill in.

Make slides from notes

Say something likeMake 5 slides for my team meeting from these notes

  1. Paste your notes, with any numbers you want to use.
  2. Say how many slides, or let Claude pick.
  3. You get a .pptx with short slide text and fuller speaker notes.
  4. Ask for changes slide by slide: "shorter title on slide 3".

It never adds figures, charts, or results you didn't give.

Make a spreadsheet

Say something likePut these expenses in a sheet with a notes column

  1. Paste your list: items, amounts, dates.
  2. Say which columns you want.
  3. You get an .xlsx with your numbers exactly as given, and totals as formulas so they stay right.

Edit a Google Sheet or Slides deck

Say something likeMake the Remarks column in my Google Sheet sound natural

  1. Connect Claude to your Google account (Settings, then Connectors), if you haven't already.
  2. Share the link to the Sheet or Slides deck in the chat.
  3. The text is fixed right there. Numbers, formulas, and layout are left alone.
  4. No connector? Download it as .xlsx or .pptx, attach it, and you get a new copy back.

Fix a long thesis, manual, or report

Say something likeFix the wording in my 120 page thesis, keep the terms consistent

  1. Attach the file. Word, PDF, or LaTeX (.tex) all work.
  2. Claude works through it section by section and keeps a list of names and terms so they stay the same.
  3. You get a new copy ending in -humanized, plus a short note of anything it wasn't sure about.
  4. For LaTeX, only the prose changes. Commands, maths, and citations stay exactly as they were.

Your voice

Build my voice profile

Say something likeMake a quick voice profile from these 3 messages

  1. For a quick start, paste 3 short messages you wrote yourself.
  2. You get a short profile: how long your sentences run, words you like, how you sign off.
  3. Save it as a note or file and attach it next time: "use my voice profile".
  4. Add more of your writing later to make it better, or keep a "work me" and a "personal me".

Only your own writing. It won't copy anyone else's voice.

Set up a team style guide

Say something likeHelp me make a style guide for my bakery's messages

  1. Ask for a style guide, or attach one you already have.
  2. Fill in the blanks: product names, words to use and avoid, how you sign off.
  3. Save it and attach it whenever you write for the team.
  4. Every message then follows it, and product names stay spelled exactly.

Small business

Send a payment reminder

Say something likeWrite a polite reminder for invoice 1043, Rs 18,500, due on 5 March

  1. Give the invoice number, the amount, and the due date.
  2. Say whether it's the first reminder or a follow-up.
  3. You get a short, polite message for email or WhatsApp, firmer for later reminders.
  4. Amounts, dates, and invoice numbers stay exactly as you gave them.

Reply to a customer

Say something likeReply to this customer whose order arrived late

  1. Paste the customer's message and the facts: order number, what went wrong, what you'll do.
  2. You get a reply that says sorry once, explains the fix, and says what happens next.
  3. It only promises what you said you'll do.

Set an out-of-office reply

Say something likeWrite an out-of-office reply, I'm away 10 to 14 March, contact Ravi

  1. Give the dates and who to contact instead.
  2. Say where it's for: email, WhatsApp Business away message, or both.
  3. You get a short reply you can paste in. Ask for an email signature too if you need one.

Send personal messages to a list of people

Say something likeMake one Diwali message per row in this sheet, using each person's name

  1. Attach a spreadsheet with names, and any detail you want used, like an order or a city.
  2. Write or describe the message once.
  3. You get a file with one draft per row. Nothing is sent.
  4. Copy each draft into WhatsApp or email yourself.

Only for people you already know, like customers or family. It won't write bulk marketing or spam.

Languages and access

Write in Hindi or Tamil script

Say something likeWrite this in Hindi script: kal subah 10 baje milte hain

  1. Paste your Hinglish or Tanglish written in English letters.
  2. Ask for it in Hindi (Devanagari) or Tamil script.
  3. You get the same words in that script. Nothing is translated.
  4. Check names and English words, since some can be spelled more than one way.

Works for Hindi and Tamil, plus Telugu, Kannada, Malayalam, Bengali, Marathi, and Gujarati.

Write alt text for images

Say something likeWrite alt text for these 3 product photos

  1. Attach the images.
  2. Say where they'll go: an Instagram post, a website, or slides.
  3. You get a short, plain description for each one.
  4. It describes only what's visible and never guesses who people are.

Make something Easy Read or dyslexia friendly

Say something likeMake this Word file dyslexia friendly

  1. Attach the file or paste the text.
  2. Ask for Easy Read for short, simple lines with picture suggestions, or dyslexia friendly for a clearer layout.
  3. Dyslexia friendly keeps every word and changes only the font, spacing, and alignment. You get a new copy ending in -readable.
  4. Easy Read rewrites in simpler words, so check that nothing important was left out.

For developers

Write or fix a README

Say something likeWrite a README for this project

  1. In Claude Code, ask with the project open. Elsewhere, paste your README and say what the project does.
  2. You get a short opening that says what it is and who it's for, then install, quick start, and usage.
  3. Install steps use the real commands from your repo. If one is missing, you get a clear TODO instead of a guess.
  4. Emoji on every heading, walls of badges, and sales words are cut.

Commands, code blocks, paths, and version numbers stay exactly as written. It never adds a feature the project doesn't have.

Write a commit message or PR description

Say something likeWrite a commit message for my staged changes

  1. In Claude Code, just ask: it reads your staged changes. Elsewhere, paste the diff or a list of what changed.
  2. You get a summary line under about 72 characters, plus a line or two on why if it helps.
  3. For a PR, you get what changed, why, and how to check it, following your repo's PR template if there is one.
  4. It follows your repo's style, like fix(login): or a ticket prefix, and doesn't commit unless you ask.

It describes only what's in the diff. It won't say tests were added or passed unless they were.

Explain the architecture or folder structure

Say something likeExplain our folder structure for a new teammate

  1. In Claude Code, ask with the project open. Elsewhere, paste the folder tree (tree -L 2) or a screenshot of it.
  2. For a folder structure, you get the tree plus one line per folder: what lives there and when you'd edit it.
  3. For an architecture doc, you get the main parts, what each one talks to, and one real request followed from start to finish.
  4. For a decision record (ADR), give the choice and your reasons. You get short Context, Decision, and Consequences sections.

It uses the real names of folders and services and never invents parts your code doesn't have. It never moves or creates code files.

Clean up code comments without touching the code

Say something likeClean up the comments in billing.py, leave the code alone

  1. Attach or paste the file, or ask in Claude Code with the project open.
  2. Only comments and docstrings are rewritten, mostly to explain why the code does something.
  3. A script puts each comment back in its place and refuses to save if any code would change.
  4. You get a new copy ending in -humanized (in a git repo, the file is edited in place), plus a list of comments worth deleting.

Licence headers, tool directives like noqa, commented-out code, TODOs, and @param names are left as they are.

Write clearer error messages and app text

Say something likeMake these error messages friendlier

  1. Paste the messages, button labels, or translation file (like en.json), and say what the code does if it isn't clear.
  2. Each error message says what happened and what the person can do now.
  3. Buttons say what they do, and empty screens say what to do next.
  4. In a translation file, only the English values change. Keys and placeholders like {name} stay exactly.

API docs work too: paste the endpoint and you get a plain description, a parameter table, and an example with your real field names.
